# O pedido da vez

> Isto **não** vai em campo nenhum do Project. É o que você digita no chat,
> toda vez que usa. Repare no tamanho: uma frase.
> Ele é curto porque tudo que seria repetição já está nas Instruções.

## O pedido de todo dia

```
Anexei o relatório de OS de hoje. Monta a pauta da reunião das 8h.
```

É isso. Sem explicar o que é OS, sem pedir tabela, sem lembrar do formato de
data, sem avisar que a planilha vem suja. Tudo isso está escrito uma vez, nas
Instruções, e vale em toda conversa nova.

## Variações que continuam curtas

Todas mudam o **recorte**, nunca o formato. O formato já está combinado.

```
Anexei o relatório de OS. Só as atrasadas, e agrupa por máquina.
```

```
Anexei o relatório de OS. Quero só o que vence nos próximos 3 dias úteis.
```

```
Anexei o relatório de OS. Compara a carga das seis máquinas e diz onde sobra folga.
```

```
Anexei o relatório de OS. Antes da pauta, me diga o que você teve que normalizar.
```

## Quando o pedido cresce, é sinal

Se você se pegou escrevendo de novo *"lembre que valor vai com vírgula"* ou
*"não me traz introdução"*, aquilo **não era pedido, era regra**. O lugar dela é
nas Instruções, e é exatamente a regra do 2× da aula: corrigiu duas vezes,
vira linha do arquivo.

## O teste de uma linha

> Se você tivesse que mandar este mesmo pedido na semana que vem, mudaria
> alguma palavra? Se sim, essa palavra é a única parte que é pedido de verdade.
> O resto é regra, e regra fica guardada.
